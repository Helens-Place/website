This post is set to `draft: true`, so it does not appear on the live site. It
exists as a template for Helen to duplicate in TinaCMS.

## How to use it

Write in plain paragraphs. Use a second level heading to break up longer pieces,
and keep paragraphs short, which suits every reader and particularly a dyslexic
one.

## When it is ready

Set draft to false and publish. The post then appears at the top of the blog
index automatically, ordered by its date.
