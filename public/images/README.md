# Photos for helensplace.co.uk

Save the photos here, in this folder, using exactly these filenames. The site
renders a labelled placeholder block wherever a file is missing, so nothing
breaks while they are still to come. Drop a file in and it appears on the next
build, no code changes needed.

Please save JPEGs at roughly 2000px on the long edge and under about 500KB.
